## Welcome

- neococo is a modern implementation of the Bot protocol based on NTQQ.
  - neococo 是基于 NTQQ 的现代化 Bot 协议端实现

## Feature

- **Easy to Use**
  - 作为初学者能够轻松使用。
- **Quick and Efficient**
  - 可在低内存环境中长期运行。
- **Rich API Interface**
  - 覆盖 OneBot 11 标准接口与常用扩展接口。
- **Stable and Reliable**
  - 持续维护，并跟随 NTQQ 版本更新完成适配。

## Quick Start

从仓库的 Releases 页面获取最新版本。首次使用时，请先阅读仓库内的部署说明，完成账号登录与 OneBot 服务配置。
